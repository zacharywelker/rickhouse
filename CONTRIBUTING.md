# Contributing to Rickhouse

Thanks for taking an interest. Rickhouse is a small, personal project, and this page says what helps and what to expect.

## What is welcome now

- **Bug reports, questions and ideas.** Open an [issue](https://github.com/zacharywelker/rickhouse/issues). Say whether it is the web app or the iPhone app, what you did and what you expected. Don't paste passwords, tokens or your server address.
- **Running it yourself and telling us what broke.** The install guide is [`docs/UNRAID.md`](docs/UNRAID.md).

## Code contributions: not yet

**Pull requests with code are not being accepted right now.** This is not a judgment of your work. Rickhouse is licensed under the AGPL-3.0-or-later and the author also ships the iOS app through the App Store, and Apple's terms do not fit with code that others have contributed under the AGPL alone. To keep both possible, outside code will only be accepted once a contributor license agreement (CLA) is in place, so that contributors grant the author the right to relicense and distribute their changes.

Until that exists:

- Please open an issue instead of a pull request, and describe the change you would like.
- Pull requests from outside contributors will be closed without review, with a pointer to this page.

This page will be updated when the CLA is set up.
