# Aileron

Source: https://open-foundry.com/fonts/aileron

Aileron is released for free, unrestricted use (including commercial use)
by its designer. No license file ships with the download; this note
records provenance for an open-source project. If a signed license
becomes available it should replace this note.

Files here are `.woff2` conversions (via fonttools) of the original
`.otf` files, limited to the weights this project uses: Regular,
SemiBold, and Bold, each with italics.
