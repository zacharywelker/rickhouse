# Tournaments, Plan 3: The server (migration, state machine, ranking and API)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A signed-in user can make, preview, start, play, undo, withdraw from and finish a tournament, and read the long-term ranking and the rating audit, through `/api/v1/tournaments`, with every rule enforced on the server.

**Architecture:** Four tables (one hand-written migration). The engine from Plan 2 (already on `main`) does the sorting, flight cutting, advancement and ranking. Around it: `entrants` (database rows to engine input) and `view` (the API's shape and the blind rule) are pure; `facts` loads what the grouping needs about each entry; `state` locks a tournament, reads it, generates a round and `settle`s a finished round onward; `lifecycle` and `heats` are the commands, each one transaction that locks the tournament first; `queries` and `ranking-query` read; then `api-schemas`, `http` and twelve thin route files. Behavior is pinned by pure unit tests, mocked route tests (this repo's pattern) and opt-in integration tests against a throwaway Postgres.

**Tech Stack:** Next.js route handlers (this repo's version differs from older ones; see `AGENTS.md`), Drizzle ORM with raw SQL where a view is involved, Postgres 16, zod, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-13-tournament-design.md`, sections 3 to 7. Plan 2 (the engine) is merged. A working, verified version of everything in this plan exists as the local branch `claude/tournament-server-prototype` (commit `1ddcc6b`, worktree `.worktrees/tournament-server`); the code below is that code, and an executor may diff against it. Do not push the prototype branch.

## Global Constraints

- Migration: hand-written (drizzle-kit generate does not work here), numbered after the highest on `main` (0040 when this was written; if `main` has a newer one, use the next number everywhere), with its `drizzle/meta/_journal.json` entry (`when` = previous + 86400000), the annotated section in `schema.sql`, and the Drizzle mirror in `src/db/schema.ts`, all in lockstep.
- Tables (spec section 3): `tournaments`, `tournament_entries`, `tournament_heats`, `tournament_heat_entries`. An entry is a bottle (bottle and its label), a label with no bottle, or ad hoc (neither); its `display_name` is a snapshot. Composite foreign keys hold the owner's own bottle and label (`(expression_id, owner_id)` and `(bottle_id, expression_id)`); deleting a bottle keeps its entry on the label, deleting a label leaves an ad hoc entry.
- Every command runs in one `db.transaction` and begins with `lockTournament` (`SELECT ... FOR UPDATE` scoped to the owner), so two requests cannot interleave. A tournament that is not the caller's is a 404, never a 403.
- Failures: 404 gone or not yours, 409 not allowed in the current state, 422 bad input. API error codes are `not_found`, `conflict` and `invalid` (plus `unauthorized` for a 401), through `apiError` in `src/lib/api/v1.ts`. API v1 is additive only: this plan adds endpoints and changes none.
- Blind rule: in an **active blind** tournament, a **pending** flight is returned `hidden` with no entries, no entry ids, no facts and no generated label: only its proof band, its entry count and its glass letters. A decided flight is revealed. The one place that names the contents of a pending blind flight is the response to `draw`, which is for the pourer. (Amended after execution: the owner's own flight name is withheld too; see the web plan.) In a draft nothing is hidden.
- Heat size is 2 to 4 and a tournament needs at least two entries to start; the engine's `RangeError`s are a last line of defense and are never what a user sees. At most 500 entries per tournament.
- Ranking: ad hoc entries are never ranked; competitor ids are `b:<bottleId>` and `e:<expressionId>`; with a category filter, competitors outside the category are removed from each flight before the fit.
- SAFETY: never run the app, a script or a test against the real database. The worktree's `.env` must have a `DATABASE_URL` ending `/rickhouse_tourney_proto` (Task 0), every command that touches the database starts with the guard shown in the steps, and the main checkout's `.env` is never edited (a past chain of commands rewrote it by accident; see Task 0).
- `AGENTS.md` is regenerated by `next dev` in each worktree; do not commit it. Match the surrounding code's comment density and naming. Do not add a dependency. Do not open a pull request unless the user asks.

## Review Focus

1. **Two requests at once** (a double tap, or two devices) recording the same flight: exactly one succeeds and the other gets a 409, and places are not corrupted. Test: "records a flight once even when two requests arrive together".
2. **Another account's ids**: a tournament, flight, entry, bottle or label that is not the caller's, or a flight or entry that belongs to a different tournament of the same owner, is a 404 (or a 422 for a bottle or label in a request body), and changes nothing. Tests: the stranger checks in each integration file and "does not find a flight or an entry that belongs to another tournament".
3. **A blind leak**: names, entry ids or the generated label of a pending blind flight appearing in `GET`, `start`, `reset` or any command's returned view. Tests: the view's blind tests, "hides a blind tournament's pending flights", and the HTTP check in Task 9.
4. **A bottle or label that a tournament points at is deleted or merged**: the entry must survive (kept on the label, or ad hoc), the label merge must carry entries along instead of failing a foreign key, and history must still read. Tests: "keeps the history when a bottle is deleted" and "follows a label that is merged into another" (which fails with a foreign-key error without the fix in Task 1).
5. **A large field**: 300 bottles in flights of 2 started in 0.2 s, returned a 95 KB view in 13 ms and recorded a flight in 20 ms on the machine this was checked on; treat a result an order of magnitude worse as a failure. Test: "plays a field of 60 to its end" (and the optional timing step in Task 9).

Append this to the end of `src/db/schema.ts` (the composite foreign keys live in the migration, as for `tasting_notes`):

```ts
// ------------------------------------------------------------
// Tournaments (docs/superpowers/specs/2026-10-13-tournament-design.md)
// ------------------------------------------------------------

export type TournamentStatus = "draft" | "active" | "complete";
export type HeatStatus = "pending" | "decided" | "bye";

export const tournaments = pgTable(
  "tournaments",
  {
    id: serial("id").primaryKey(),
    ownerId: integer("owner_id")
      .notNull()
      .references((): AnyPgColumn => users.id, { onDelete: "cascade" }),
    name: text("name").notNull(),
    status: text("status").notNull().default("draft").$type<TournamentStatus>(),
    /** One flight size per tournament, 2 to 4. */
    heatSize: smallint("heat_size").notNull(),
    seeding: text("seeding").notNull().default("similar").$type<"similar" | "random">(),
    /** What flights are matched on, highest priority first: each of the five keys exactly once. */
    groupOrder: text("group_order").array().notNull().default(sql`'{proof,mashbill,distillery,age,finish}'::text[]`),
    blind: boolean("blind").notNull().default(false),
    /** How the field was chosen, for display only. */
    fieldNote: text("field_note"),
    createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
    startedAt: timestamp("started_at", { withTimezone: true }),
    completedAt: timestamp("completed_at", { withTimezone: true }),
  },
  (t) => [
    index("tournaments_owner_idx").on(t.ownerId, t.createdAt.desc()),
    check("tournaments_status_check", sql`${t.status} IN ('draft', 'active', 'complete')`),
    check("tournaments_heat_size_check", sql`${t.heatSize} BETWEEN 2 AND 4`),
    check("tournaments_seeding_check", sql`${t.seeding} IN ('similar', 'random')`),
  ],
);

/**
 * A bottle (bottleId and its label), a label with no bottle (expressionId only), or ad hoc (neither).
 * `displayName` is a snapshot, so history survives deletion. The owner's own bottle and label are held by composite
 * foreign keys in the migration: `(expression_id, owner_id)` and `(bottle_id, expression_id)`.
 */
export const tournamentEntries = pgTable(
  "tournament_entries",
  {
    id: serial("id").primaryKey(),
    tournamentId: integer("tournament_id").notNull(),
    ownerId: integer("owner_id").notNull(),
    bottleId: integer("bottle_id"),
    expressionId: integer("expression_id"),
    displayName: text("display_name").notNull(),
    status: text("status").notNull().default("active").$type<"active" | "withdrawn">(),
    seed: integer("seed").notNull().default(0),
  },
  (t) => [
    index("tournament_entries_tournament_idx").on(t.tournamentId),
    uniqueIndex("tournament_entries_bottle_unique").on(t.tournamentId, t.bottleId).where(sql`${t.bottleId} IS NOT NULL`),
    check("tournament_entries_status_check", sql`${t.status} IN ('active', 'withdrawn')`),
  ],
);

export const tournamentHeats = pgTable(
  "tournament_heats",
  {
    id: serial("id").primaryKey(),
    tournamentId: integer("tournament_id")
      .notNull()
      .references(() => tournaments.id, { onDelete: "cascade" }),
    round: smallint("round").notNull(),
    slot: smallint("slot").notNull(),
    /** Set only when the owner renames the heat; the generated label is computed on read. */
    label: text("label"),
    status: text("status").notNull().default("pending").$type<HeatStatus>(),
    decidedAt: timestamp("decided_at", { withTimezone: true }),
    decidedBy: integer("decided_by").references((): AnyPgColumn => users.id, { onDelete: "set null" }),
  },
  (t) => [
    unique("tournament_heats_round_slot_unique").on(t.tournamentId, t.round, t.slot),
    check("tournament_heats_status_check", sql`${t.status} IN ('pending', 'decided', 'bye')`),
  ],
);

export const tournamentHeatEntries = pgTable(
  "tournament_heat_entries",
  {
```

```ts
import type { Entrant, MashbillInput } from "./types";

/** One of a label's mashbills as the database gives it: grain shares arrive as numeric strings. */
export type MashbillRow = {
  name: string | null;
  isGeneric: boolean;
  isSecret: boolean;
  grains: { grain: string; percent: string | number }[];
};

/**
 * What the database knows about an entry, before it is made into an `Entrant`: the bottle's own values over its
 * release's over its label's (the data layer resolves that), the label's lists, and its category's field group.
 */
export type EntryFacts = {
  proof: string | number | null;
  ageYears: string | number | null;
  ageMonths: number | null;
  ageDays: number | null;
  fieldGroup: string | null;
  distilleries: string[];
  finishes: string[];
  mashbills: MashbillRow[];
};

export type EntryKind = "bottle" | "label" | "adhoc";

type EntryIds = { bottleId: number | null; expressionId: number | null };

/** A bottle entry has its bottle, a label entry only its label, an ad hoc entry neither. */
export function entryKind(entry: EntryIds): EntryKind {
  return entry.bottleId !== null ? "bottle" : entry.expressionId !== null ? "label" : "adhoc";
}

/** The id the ranking knows an entry by across tournaments, or null for an ad hoc entry, which is never ranked. */
export function competitorId(entry: EntryIds): string | null {
  return entry.bottleId !== null ? `b:${entry.bottleId}` : entry.expressionId !== null ? `e:${entry.expressionId}` : null;
}

const present = (text: string | null): string | null => (text !== null && text.trim() !== "" ? text.trim() : null);

/** A bottle as it reads in a tournament: brand and label, then what marks it (pick, barrel, release or batch). */
export function entryDisplayName(parts: {
  brand: string;
  name: string;
  pickName: string | null;
  barrelNumber: string | null;
  releaseName: string | null;
  batch: string | null;
}): string {
  const base = `${parts.brand} ${parts.name}`;
  const pick = present(parts.pickName);
  if (pick) return `${base} “${pick}”`;
  const barrel = present(parts.barrelNumber);
  if (barrel) return `${base} (barrel ${barrel})`;
  const release = present(parts.releaseName);
  if (release) return `${base} (${release})`;
  const batch = present(parts.batch);
  if (batch) return `${base} (batch ${batch})`;
  return base;
}

/** A database numeric string (or number) as a number, or null when it is missing or not a number. */
export function toNumber(value: string | number | null): number | null {
  if (value === null) return null;
  const n = typeof value === "number" ? value : Number(value);
  return Number.isFinite(n) ? Math.round(n * 100) / 100 : null;
}

/** Years, with months and days added in, or null when none of the three is recorded. */
function ageInYears(years: string | number | null, months: number | null, days: number | null): number | null {
  const y = toNumber(years);
  if (y === null && months === null && days === null) return null;
  return Math.round(((y ?? 0) + (months ?? 0) / 12 + (days ?? 0) / 365.25) * 100) / 100;
}

function mashbillInput(rows: MashbillRow[], fieldGroup: string | null): MashbillInput | null {
  if (fieldGroup !== "whiskey" || rows.length === 0) return null;
  if (rows.length > 1) return { kind: "blend" };
  const row = rows[0]!;
  if (row.isGeneric) return { kind: "generic", style: row.name ?? "" };
  return {
    kind: "recipe",
    name: row.isSecret ? row.name : null,
    grains: row.grains.flatMap((g) => {
      const percent = toNumber(g.percent);
      return percent === null ? [] : [{ grain: g.grain, percent }];
    }),
  };
}

/** An entry as the grouping sees it. A value the data does not give, or gives badly, is unknown (null). */
export function buildEntrant(id: number, name: string, facts: EntryFacts): Entrant {
  return {
    id,
    name,
    proof: toNumber(facts.proof),
    mashbill: mashbillInput(facts.mashbills, facts.fieldGroup),
    distilleries: facts.distilleries,
    ageYears: ageInYears(facts.ageYears, facts.ageMonths, facts.ageDays),
    finishes: facts.finishes,
  };
}
```

```ts
import { autoLabel, heatBand } from "./grouping";
import { entryKind, type EntryKind } from "./entrants";
import { planRounds, standings, type HeatResult } from "./rounds";
import type { Entrant } from "./types";

export type TournamentRow = {
  id: number;
  name: string;
  status: "draft" | "active" | "complete";
  heatSize: number;
  seeding: "similar" | "random";
  groupOrder: string[];
  blind: boolean;
  fieldNote: string | null;
  createdAt: Date;
  startedAt: Date | null;
  completedAt: Date | null;
};
export type EntryRow = {
  id: number;
  displayName: string;
  status: "active" | "withdrawn";
  bottleId: number | null;
  expressionId: number | null;
  seed: number;
};
export type HeatRow = { id: number; round: number; slot: number; label: string | null; status: "pending" | "decided" | "bye" };
export type HeatEntryRow = { heatId: number; entryId: number; place: number | null; glass: string | null };

/** What the view is built from: the rows, and what the grouping knows about each entry (see `loadEntrants`). */
export type ViewInput = {
  tournament: TournamentRow;
  entries: EntryRow[];
  heats: HeatRow[];
  heatEntries: HeatEntryRow[];
  entrants: ReadonlyMap<number, Entrant>;
};

export type ViewEntry = {
  id: number;
  name: string;
  status: "active" | "withdrawn";
  kind: EntryKind;
  bottleId: number | null;
  expressionId: number | null;
};

/** A heat's entry as the owner sees it. */
export type ViewHeatEntry = {
  entryId: number;
  name: string;
  place: number | null;
  glass: string | null;
  proof: number | null;
  mashbill: string | null;
  ageYears: number | null;
  distilleries: string[];
};

export type ViewHeat = {
  id: number;
  round: number;
  slot: number;
  status: "pending" | "decided" | "bye";
  /** The owner's own name for the heat, or null. */
  label: string | null;
  /** What the heat's bottles share ("MGP 95/5"), or null; hidden while a blind heat is pending. */
  autoLabel: string | null;
  /** "90 to 94 proof"; empty when a proof is unknown. Shown even for a hidden heat. */
  band: string;
  /** True for a pending heat of an active blind tournament: names, facts and entry ids are withheld. */
  hidden: boolean;
  entryCount: number;
  /** The glass letters set so far, in order; for a hidden heat this is all that is known of its entries. */
  glasses: string[];
  entries: ViewHeatEntry[];
};

export type ViewStanding = { entryId: number; name: string; rank: number; round: number; place: number | null };

export type TournamentView = {
  id: number;
  name: string;
  status: TournamentRow["status"];
  heatSize: number;
  seeding: TournamentRow["seeding"];
  groupOrder: string[];
  blind: boolean;
  fieldNote: string | null;
  createdAt: string;
  startedAt: string | null;
  completedAt: string | null;
  entries: ViewEntry[];
  rounds: { round: number; heats: ViewHeat[] }[];
  /** Heats per round, from the field's size to the final, assuming no one withdraws. Empty under two entrants. */
  plan: number[];
  currentRound: number | null;
  /** Heats of the current round that are decided or byes, out of all of them. */
  progress: { done: number; total: number };
  /** Who finished where, once at least one heat has a result. Names are revealed, since those heats are decided. */
  standings: ViewStanding[];
  champion: { entryId: number; name: string } | null;
};

const iso = (d: Date | null): string | null => (d ? d.toISOString() : null);

/** A tournament as the API returns it, with the blind rule applied: a pending heat of an active blind one is hidden. */
export function buildView(input: ViewInput): TournamentView {
  const { tournament, entries, heats, heatEntries, entrants } = input;
  const nameOf = new Map(entries.map((e) => [e.id, e.displayName]));
  const byHeat = new Map<number, HeatEntryRow[]>();
  for (const row of heatEntries) byHeat.set(row.heatId, [...(byHeat.get(row.heatId) ?? []), row]);

  const hideBlind = tournament.status === "active" && tournament.blind;
  const viewHeat = (heat: HeatRow): ViewHeat => {
    const rows = [...(byHeat.get(heat.id) ?? [])].sort((a, b) => (a.place ?? 99) - (b.place ?? 99) || a.entryId - b.entryId);
    const members = rows.map((r) => entrants.get(r.entryId)).filter((e): e is Entrant => e !== undefined);
    const hidden = hideBlind && heat.status === "pending";
    const glasses = rows.map((r) => r.glass).filter((g): g is string => g !== null).sort();
    return {
      id: heat.id,
      round: heat.round,
      slot: heat.slot,
      status: heat.status,
      label: heat.label,
      autoLabel: hidden ? null : autoLabel(members),
      band: heatBand(members),
      hidden,
      entryCount: rows.length,
      glasses,
      entries: hidden
        ? []
        : rows.map((r) => {
            const e = entrants.get(r.entryId);
            return {
              entryId: r.entryId,
              name: nameOf.get(r.entryId) ?? "",
              place: r.place,
              glass: r.glass,
              proof: e?.proof ?? null,
              mashbill: e?.mashbill ? mashbillDisplay(e.mashbill) || null : null,
              ageYears: e?.ageYears ?? null,
              distilleries: e?.distilleries ?? [],
            };
          }),
    };
  };

  const ordered = [...heats].sort((a, b) => a.round - b.round || a.slot - b.slot);
  const rounds = [...new Set(ordered.map((h) => h.round))].map((round) => ({
    round,
    heats: ordered.filter((h) => h.round === round).map(viewHeat),
  }));
  const currentRound = rounds.length > 0 ? rounds[rounds.length - 1]!.round : null;
  const currentHeats = rounds.length > 0 ? rounds[rounds.length - 1]!.heats : [];

  const results: HeatResult[] = ordered
    .filter((h) => h.status !== "pending")
    .map((h) => ({
      round: h.round,
      kind: h.status === "bye" ? "bye" : "ranked",
      entries: (byHeat.get(h.id) ?? []).map((r) => ({ entryId: r.entryId, place: r.place })),
    }));
  const rankedAnything = results.some((r) => r.kind === "ranked");
  const standing = rankedAnything
    ? standings(results).map((s) => ({ entryId: s.entryId, name: nameOf.get(s.entryId) ?? "", rank: s.rank, round: s.round, place: s.place }))
    : [];

  const activeCount = entries.filter((e) => e.status === "active").length;
  const champion = tournament.status === "complete" ? standing.find((s) => s.rank === 1) : undefined;
  return {
    id: tournament.id,
    name: tournament.name,
    status: tournament.status,
    heatSize: tournament.heatSize,
    seeding: tournament.seeding,
    groupOrder: tournament.groupOrder,
    blind: tournament.blind,
    fieldNote: tournament.fieldNote,
    createdAt: tournament.createdAt.toISOString(),
    startedAt: iso(tournament.startedAt),
    completedAt: iso(tournament.completedAt),
    entries: [...entries]
      .sort((a, b) => a.seed - b.seed || a.id - b.id)
      .map((e) => ({ id: e.id, name: e.displayName, status: e.status, kind: entryKind(e), bottleId: e.bottleId, expressionId: e.expressionId })),
    rounds,
    plan: activeCount >= 2 ? planRounds(activeCount, tournament.heatSize) : [],
    currentRound,
    progress: { done: currentHeats.filter((h) => h.status !== "pending").length, total: currentHeats.length },
    standings: standing,
    champion: champion ? { entryId: champion.entryId, name: champion.name } : null,
  };
}
```

```ts
/** An entry as far as loading its facts needs. */
export type EntryRef = { id: number; displayName: string; bottleId: number | null; expressionId: number | null };

const list = (ids: number[]): SQL => sql.join(ids.map((id) => sql`${id}`), sql`, `);

type ValueRow = {
  id: number;
  proof: string | null;
  age_years: string | null;
  age_months: number | null;
  age_days: number | null;
  field_group?: string | null;
};

/**
 * What the grouping needs to know about each entry, by entry id: a bottle's proof and age (its own over its release's
 * over its label's, as the bottle list resolves them), a label-only entry's from the label, and for both the
 * label's distilleries, finishes (in their listed order) and mashbills. An ad hoc entry has none, so it sorts last.
 * Only the owner's own bottles and labels are read.
 */
export async function loadEntrants(tx: Tx, ownerId: number, entries: EntryRef[]): Promise<Map<number, Entrant>> {
  const run = async <T>(query: SQL): Promise<T[]> => (await tx.execute(query)) as unknown as T[];
  const bottleIds = [...new Set(entries.flatMap((e) => (e.bottleId !== null ? [e.bottleId] : [])))];
  const expressionIds = [...new Set(entries.flatMap((e) => (e.expressionId !== null ? [e.expressionId] : [])))];

  const bottleRows = bottleIds.length
    ? await run<ValueRow>(sql`SELECT id, proof, age_years, age_months, age_days FROM bottle_list WHERE owner_id = ${ownerId} AND id IN (${list(bottleIds)})`)
    : [];
  const labelRows = expressionIds.length
    ? await run<ValueRow>(sql`SELECT e.id, e.proof, e.age_years, e.age_months, e.age_days, c.field_group
        FROM expressions e JOIN categories c ON c.id = e.category_id
        WHERE e.owner_id = ${ownerId} AND e.id IN (${list(expressionIds)})`)
    : [];
  const distilleryRows = expressionIds.length
    ? await run<{ expression_id: number; name: string }>(sql`SELECT ed.expression_id, d.name FROM expression_distilleries ed
        JOIN distilleries d ON d.id = ed.distillery_id WHERE ed.expression_id IN (${list(expressionIds)})
        ORDER BY ed.expression_id, ed."position", d.id`)
    : [];
  const finishRows = expressionIds.length
    ? await run<{ expression_id: number; name: string }>(sql`SELECT ef.expression_id, f.name FROM expression_finishes ef
        JOIN finishes f ON f.id = ef.finish_id WHERE ef.expression_id IN (${list(expressionIds)})
        ORDER BY ef.expression_id, ef."position", f.id`)
    : [];
  const mashbillRows = expressionIds.length
    ? await run<{ expression_id: number; mashbill_id: number; name: string | null; is_generic: boolean; is_secret: boolean }>(
        sql`SELECT em.expression_id, m.id AS mashbill_id, m.name, m.is_generic, m.is_secret FROM expression_mashbills em
          JOIN mashbills m ON m.id = em.mashbill_id WHERE em.expression_id IN (${list(expressionIds)})
          ORDER BY em.expression_id, em."position", m.id`,
      )
    : [];
  const mashbillIds = [...new Set(mashbillRows.map((m) => m.mashbill_id))];
  const grainRows = mashbillIds.length
    ? await run<{ mashbill_id: number; grain: string; percent: string }>(sql`SELECT mashbill_id, grain, percent FROM mashbill_grains
        WHERE mashbill_id IN (${list(mashbillIds)}) ORDER BY mashbill_id, "position", id`)
    : [];

  const bottleById = new Map(bottleRows.map((r) => [r.id, r]));
  const labelById = new Map(labelRows.map((r) => [r.id, r]));
  const grouped = <T extends { expression_id: number }>(rows: T[]) => {
    const out = new Map<number, T[]>();
    for (const row of rows) out.set(row.expression_id, [...(out.get(row.expression_id) ?? []), row]);
    return out;
  };
  const distilleries = grouped(distilleryRows);
  const finishes = grouped(finishRows);
  const mashbills = grouped(mashbillRows);
  const grainsOf = new Map<number, { grain: string; percent: string }[]>();
  for (const g of grainRows) grainsOf.set(g.mashbill_id, [...(grainsOf.get(g.mashbill_id) ?? []), { grain: g.grain, percent: g.percent }]);

  const result = new Map<number, Entrant>();
  for (const entry of entries) {
    const label = entry.expressionId !== null ? labelById.get(entry.expressionId) : undefined;
    const bottle = entry.bottleId !== null ? bottleById.get(entry.bottleId) : undefined;
    const values = bottle ?? label;
    const exprId = entry.expressionId;
    const facts: EntryFacts = {
      proof: values?.proof ?? null,
      ageYears: values?.age_years ?? null,
      ageMonths: values?.age_months ?? null,
      ageDays: values?.age_days ?? null,
      fieldGroup: label?.field_group ?? null,
      distilleries: exprId !== null ? (distilleries.get(exprId) ?? []).map((d) => d.name) : [],
      finishes: exprId !== null ? (finishes.get(exprId) ?? []).map((f) => f.name) : [],
      mashbills:
        exprId !== null
          ? (mashbills.get(exprId) ?? []).map(
              (m): MashbillRow => ({ name: m.name, isGeneric: m.is_generic, isSecret: m.is_secret, grains: grainsOf.get(m.mashbill_id) ?? [] }),
            )
          : [],
    };
    result.set(entry.id, buildEntrant(entry.id, entry.displayName, facts));
  }
  return result;
}
```

```ts
/**
 * Cuts the given entries into heats and adds them to `round`, numbered on after any heats already there. Similar
 * seeding matches them by the tournament's key order; random shuffles them. A heat of one is a bye.
 */
export async function generateRound(tx: Tx, ownerId: number, t: TournamentRow, round: number, entryIds: number[]): Promise<void> {
  if (entryIds.length === 0) return;
  const rows = await tx
    .select({
      id: tournamentEntries.id,
      displayName: tournamentEntries.displayName,
      bottleId: tournamentEntries.bottleId,
      expressionId: tournamentEntries.expressionId,
    })
    .from(tournamentEntries)
    .where(and(eq(tournamentEntries.tournamentId, t.id), inArray(tournamentEntries.id, entryIds)));
  const byId = new Map(rows.map((r) => [r.id, r]));
  const ordered = entryIds.flatMap((id) => (byId.has(id) ? [byId.get(id)!] : []));
  const entrants = await loadEntrants(tx, ownerId, ordered);
  const list = ordered.map((r) => entrants.get(r.id)!);
  const groups = t.seeding === "random" ? groupAtRandom(list, t.heatSize) : groupIntoHeats(list, t.groupOrder as GroupKey[], t.heatSize);

  const [top] = await tx
    .select({ slot: sql<number>`coalesce(max(${tournamentHeats.slot}), 0)`.mapWith(Number) })
    .from(tournamentHeats)
    .where(and(eq(tournamentHeats.tournamentId, t.id), eq(tournamentHeats.round, round)));
  let slot = top?.slot ?? 0;
  for (const group of groups) {
    slot += 1;
    const [heat] = await tx
      .insert(tournamentHeats)
      .values({ tournamentId: t.id, round, slot, status: group.length === 1 ? "bye" : "pending" })
      .returning({ id: tournamentHeats.id });
    await tx.insert(tournamentHeatEntries).values(group.map((e) => ({ heatId: heat!.id, entryId: e.id, tournamentId: t.id })));
  }
}

/**
 * Moves a finished round on. When every heat of the current round is decided (a bye counts), the next round is made
 * from the advancers, less anyone withdrawn; and when the round was a single heat, or fewer than two remain, the
 * tournament is complete. Does nothing while any heat of the round is still pending.
 */
export async function settle(tx: Tx, ownerId: number, t: TournamentRow): Promise<void> {
  const { entries, heats, heatEntries } = await readState(tx, t.id);
  if (heats.length === 0) return;
  const round = Math.max(...heats.map((h) => h.round));
  const roundHeats = heats.filter((h) => h.round === round);
  if (roundHeats.some((h) => h.status === "pending")) return;

  const withdrawn = new Set(entries.filter((e) => e.status === "withdrawn").map((e) => e.id));
  const results: HeatResult[] = roundHeats.map((h) => ({
    round,
    kind: h.status === "bye" ? "bye" : "ranked",
    entries: heatEntries.filter((r) => r.heatId === h.id).map((r) => ({ entryId: r.entryId, place: r.place })),
  }));
  const pool = nextPool(results, withdrawn);
  if (roundHeats.length === 1 || pool.length < 2) {
    await tx.update(tournaments).set({ status: "complete", completedAt: new Date() }).where(eq(tournaments.id, t.id));
    return;
  }
  await generateRound(tx, ownerId, t, round + 1, pool);
}
```

```ts
/** The entries to store: each id checked to be the owner's, and each named as it will read in the tournament. */
async function resolveEntries(tx: Tx, ownerId: number, inputs: EntryInput[]): Promise<{ ok: true; rows: NewEntry[] } | Failure> {
  const bottleIds = inputs.flatMap((i) => ("bottleId" in i ? [i.bottleId] : []));
  const labelIds = inputs.flatMap((i) => ("expressionId" in i ? [i.expressionId] : []));
  if (repeats(bottleIds)) return fail(422, "A bottle is listed twice.", { entries: "A bottle is listed twice." });
  if (repeats(labelIds)) return fail(422, "A label is listed twice.", { entries: "A label is listed twice." });

  const run = async <T>(query: SQL): Promise<T[]> => (await tx.execute(query)) as unknown as T[];
  const bottles = bottleIds.length
    ? await run<{ id: number; expression_id: number; brand: string; name: string; pick_name: string | null; barrel_number: string | null; release_name: string | null; batch: string | null }>(
        sql`SELECT b.id, b.expression_id, br.name AS brand, e.name, b.pick_name, b.barrel_number, r.name AS release_name, b.batch
          FROM bottles b JOIN expressions e ON e.id = b.expression_id JOIN brands br ON br.id = e.brand_id
          LEFT JOIN expression_releases r ON r.id = b.release_id
          WHERE b.owner_id = ${ownerId} AND b.id IN (${list(bottleIds)})`,
      )
    : [];
  const labels = labelIds.length
    ? await run<{ id: number; brand: string; name: string }>(
        sql`SELECT e.id, br.name AS brand, e.name FROM expressions e JOIN brands br ON br.id = e.brand_id
          WHERE e.owner_id = ${ownerId} AND e.id IN (${list(labelIds)})`,
      )
    : [];
  const bottleById = new Map(bottles.map((b) => [b.id, b]));
  const labelById = new Map(labels.map((l) => [l.id, l]));

  const rows: NewEntry[] = [];
  for (const [seed, input] of inputs.entries()) {
    if ("bottleId" in input) {
      const b = bottleById.get(input.bottleId);
      if (!b) return fail(422, "One of those bottles is gone.", { entries: "One of those bottles is gone." });
      rows.push({
        bottleId: b.id,
        expressionId: b.expression_id,
        displayName: entryDisplayName({ brand: b.brand, name: b.name, pickName: b.pick_name, barrelNumber: b.barrel_number, releaseName: b.release_name, batch: b.batch }),
        seed,
      });
    } else if ("expressionId" in input) {
      const l = labelById.get(input.expressionId);
      if (!l) return fail(422, "One of those labels is gone.", { entries: "One of those labels is gone." });
      rows.push({ bottleId: null, expressionId: l.id, displayName: `${l.brand} ${l.name}`, seed });
    } else {
      const name = input.name.trim();
      if (name === "" || name.length > 120) return fail(422, "An outside entry needs a name of up to 120 characters.", { entries: "Name every outside entry." });
      rows.push({ bottleId: null, expressionId: null, displayName: name, seed });
    }
  }
  return { ok: true, rows };
}

/**
 * Changes a draft: its settings and/or its whole field. A change to the field or to how flights are matched makes the
 * round 1 preview stale, so it is made again (when there was one and at least two entries remain).
 */
export async function updateDraft(
  ownerId: number,
  id: number,
  patch: Partial<TournamentSettings> & { entries?: EntryInput[] },
): Promise<{ ok: true; view: TournamentView } | Failure> {
  return db.transaction(async (tx) => {
    const t = await lockTournament(tx, ownerId, id);
    if (!t) return fail(404, GONE);
    if (t.status !== "draft") return fail(409, "Only a draft can be changed.");

    const { entries, ...settings } = patch;
    const regroup = entries !== undefined || settings.heatSize !== undefined || settings.seeding !== undefined || settings.groupOrder !== undefined;
    const before = await readState(tx, id);
    const hadPreview = before.heats.length > 0;

    if (entries !== undefined) {
      const resolved = await resolveEntries(tx, ownerId, entries);
      if (!resolved.ok) return resolved;
      await tx.delete(tournamentHeats).where(eq(tournamentHeats.tournamentId, id));
      await tx.delete(tournamentEntries).where(eq(tournamentEntries.tournamentId, id));
      if (resolved.rows.length > 0) {
        await tx.insert(tournamentEntries).values(resolved.rows.map((r) => ({ tournamentId: id, ownerId, ...r })));
      }
    } else if (regroup) {
      await tx.delete(tournamentHeats).where(eq(tournamentHeats.tournamentId, id));
    }
    if (Object.keys(settings).length > 0) await tx.update(tournaments).set(settings).where(eq(tournaments.id, id));

    if (regroup && hadPreview) {
      const fresh = await lockTournament(tx, ownerId, id);
      const after = await readState(tx, id);
      const active = after.entries.filter((e) => e.status === "active").map((e) => e.id);
      if (fresh && active.length >= 2) await generateRound(tx, ownerId, fresh, 1, active);
    }
    return { ok: true as const, view: (await viewOf(tx, ownerId, id))! };
  });
}

/** Locks the field and starts the tournament, making round 1 if the draft has no preview. Needs two entries. */
export async function startTournament(ownerId: number, id: number): Promise<{ ok: true; view: TournamentView } | Failure> {
  return db.transaction(async (tx) => {
    const t = await lockTournament(tx, ownerId, id);
    if (!t) return fail(404, GONE);
    if (t.status !== "draft") return fail(409, "This tournament has already started.");
    const { entries, heats } = await readState(tx, id);
    const active = entries.filter((e) => e.status === "active").map((e) => e.id);
    if (active.length < 2) return fail(422, "A tournament needs at least two entries.", { entries: "Add at least two entries." });
    if (heats.length === 0) await generateRound(tx, ownerId, t, 1, active);
    await tx.update(tournaments).set({ status: "active", startedAt: new Date() }).where(eq(tournaments.id, id));
    await settle(tx, ownerId, { ...t, status: "active" });
    return { ok: true as const, view: (await viewOf(tx, ownerId, id))! };
  });
}

/**
 * Regroups to the automatic choice. In a draft that is all of round 1; once running it is the entries of the current
 * round's undecided heats (a decided heat is never touched). Heats you renamed or moved bottles between lose both.
 */
export async function resetRound(ownerId: number, id: number): Promise<{ ok: true; view: TournamentView } | Failure> {
  return db.transaction(async (tx) => {
    const t = await lockTournament(tx, ownerId, id);
    if (!t) return fail(404, GONE);
    if (t.status === "complete") return fail(409, "This tournament is finished.");
    const { entries, heats, heatEntries } = await readState(tx, id);
    const activeIds = new Set(entries.filter((e) => e.status === "active").map((e) => e.id));

    if (t.status === "draft") {
      if (activeIds.size < 2) return fail(422, "A tournament needs at least two entries.", { entries: "Add at least two entries." });
      await tx.delete(tournamentHeats).where(eq(tournamentHeats.tournamentId, id));
      await generateRound(tx, ownerId, t, 1, entries.filter((e) => e.status === "active").map((e) => e.id));
    } else {
      const round = Math.max(...heats.map((h) => h.round));
      const undecided = heats.filter((h) => h.round === round && h.status !== "decided");
      const regroup = [...new Set(heatEntries.filter((r) => undecided.some((h) => h.id === r.heatId) && activeIds.has(r.entryId)).map((r) => r.entryId))];
      if (undecided.length > 0) {
        await tx.delete(tournamentHeats).where(inArray(tournamentHeats.id, undecided.map((h) => h.id)));
        await generateRound(tx, ownerId, t, round, regroup);
        await settle(tx, ownerId, t);
      }
    }
    return { ok: true as const, view: (await viewOf(tx, ownerId, id))! };
  });
}
```

**Interfaces:**
- Consumes: everything from Task 4.
- Produces (`heats.ts`): `Done`, `recordHeat(ownerId, tournamentId, heatId, input, userId)`, `undoHeat`, `withdrawEntry`, `DrawnHeat`, `drawHeat`, `setGlasses`, `moveEntry`, `promoteEntry`, `renameHeat`. Each returns `{ ok: true, view }` (`drawHeat` returns `{ ok: true, heat }`) or a `Failure`.

Rules these implement: a result must rank every entry of the flight exactly once, by entry id or (for a flight poured blind) by glass letter; only a pending flight of the current round can be recorded; an undo is allowed until a flight of the next round has a result and discards the next round; a withdrawal removes the entry from undecided flights (a flight left with one is a bye, with none is deleted) and the round moves on if nothing is pending; a move needs room in the target flight and is refused in a running blind tournament; an outside entry can be matched to a bottle or label once.

```ts
import { randomInt } from "node:crypto";
import { and, eq, gt, sql } from "drizzle-orm";
import { db, schema } from "@/db";
import { loadEntrants } from "./facts";
import { fail, GONE, lockTournament, readState, settle, viewOf, type Failure } from "./state";
import { mashbillDisplay } from "./grains";
import { heatBand } from "./grouping";
import type { TournamentView, ViewHeatEntry } from "./view";

const { tournaments, tournamentEntries, tournamentHeats, tournamentHeatEntries } = schema;

const NO_HEAT = "That flight is gone.";
const NO_ENTRY = "That entry is gone.";
const LETTERS = ["A", "B", "C", "D"];

export type Done = { ok: true; view: TournamentView };

/**
 * Records a heat's result: its entries best first, either by entry id (`ranking`) or, for a heat poured blind, by
 * glass letter (`glasses`). Every entry must appear exactly once. A finished round makes the next one, or finishes
 * the tournament.
 */
export async function recordHeat(
  ownerId: number,
  tournamentId: number,
  heatId: number,
  input: { ranking: number[] } | { glasses: string[] },
  userId: number,
): Promise<Done | Failure> {
  return db.transaction(async (tx) => {
    const t = await lockTournament(tx, ownerId, tournamentId);
    if (!t) return fail(404, GONE);
    if (t.status !== "active") return fail(409, "This tournament is not running.");
    const state = await readState(tx, t.id);
    const heat = state.heats.find((h) => h.id === heatId);
    if (!heat) return fail(404, NO_HEAT);
    if (heat.round !== Math.max(...state.heats.map((h) => h.round))) return fail(409, "That flight is not in the current round.");
    if (heat.status !== "pending") return fail(409, "That flight already has a result.");

    const rows = state.heatEntries.filter((r) => r.heatId === heat.id);
    let order: number[];
    if ("glasses" in input) {
      const entryOfGlass = new Map(rows.flatMap((r) => (r.glass !== null ? [[r.glass, r.entryId] as const] : [])));
      if (entryOfGlass.size !== rows.length) return fail(422, "Set the glasses before ranking them.", { glasses: "Set the glasses first." });
      const ok = input.glasses.length === rows.length && new Set(input.glasses).size === rows.length && input.glasses.every((g) => entryOfGlass.has(g));
      if (!ok) return fail(422, "Rank every glass exactly once.", { glasses: "Rank every glass exactly once." });
      order = input.glasses.map((g) => entryOfGlass.get(g)!);
    } else {
      const ids = new Set(rows.map((r) => r.entryId));
      const ok = input.ranking.length === rows.length && new Set(input.ranking).size === rows.length && input.ranking.every((id) => ids.has(id));
      if (!ok) return fail(422, "Rank every bottle in the flight exactly once.", { ranking: "Rank every bottle exactly once." });
      order = input.ranking;
    }

    for (const [index, entryId] of order.entries()) {
      await tx
        .update(tournamentHeatEntries)
        .set({ place: index + 1 })
        .where(and(eq(tournamentHeatEntries.heatId, heat.id), eq(tournamentHeatEntries.entryId, entryId)));
    }
    await tx.update(tournamentHeats).set({ status: "decided", decidedAt: new Date(), decidedBy: userId }).where(eq(tournamentHeats.id, heat.id));
    await settle(tx, ownerId, t);
    return { ok: true as const, view: (await viewOf(tx, ownerId, t.id))! };
  });
}

/**
 * Takes a result back. Allowed until a heat of the next round has a result; the next round, which is made from this
 * one, is then discarded. A finished tournament becomes a running one again.
 */
export async function undoHeat(ownerId: number, tournamentId: number, heatId: number): Promise<Done | Failure> {
  return db.transaction(async (tx) => {
    const t = await lockTournament(tx, ownerId, tournamentId);
    if (!t) return fail(404, GONE);
    if (t.status === "draft") return fail(409, "This tournament has not started.");
    const state = await readState(tx, t.id);
    const heat = state.heats.find((h) => h.id === heatId);
    if (!heat) return fail(404, NO_HEAT);
    if (heat.status !== "decided") return fail(409, "That flight has no result to take back.");
    const later = state.heats.filter((h) => h.round > heat.round);
    if (later.some((h) => h.status === "decided")) return fail(409, "A flight in the next round already has a result. Take that back first.");

    if (later.length > 0) await tx.delete(tournamentHeats).where(and(eq(tournamentHeats.tournamentId, t.id), gt(tournamentHeats.round, heat.round)));
    await tx.update(tournamentHeatEntries).set({ place: null }).where(eq(tournamentHeatEntries.heatId, heat.id));
    await tx.update(tournamentHeats).set({ status: "pending", decidedAt: null, decidedBy: null }).where(eq(tournamentHeats.id, heat.id));
    await tx.update(tournaments).set({ status: "active", completedAt: null }).where(eq(tournaments.id, t.id));
    return { ok: true as const, view: (await viewOf(tx, ownerId, t.id))! };
  });
}

/** Removes an entry from the current round's undecided heats; a heat left with one becomes a bye, with none is deleted. */
async function removeFromUndecided(tx: Parameters<Parameters<typeof db.transaction>[0]>[0], tournamentId: number, entryId: number): Promise<void> {
  const state = await readState(tx, tournamentId);
  if (state.heats.length === 0) return;
  const round = Math.max(...state.heats.map((h) => h.round));
  for (const heat of state.heats.filter((h) => h.round === round && h.status !== "decided")) {
    const rows = state.heatEntries.filter((r) => r.heatId === heat.id);
    if (!rows.some((r) => r.entryId === entryId)) continue;
    await tx.delete(tournamentHeatEntries).where(and(eq(tournamentHeatEntries.heatId, heat.id), eq(tournamentHeatEntries.entryId, entryId)));
    const left = rows.length - 1;
    if (left === 0) await tx.delete(tournamentHeats).where(eq(tournamentHeats.id, heat.id));
    else await tx.update(tournamentHeats).set({ status: left === 1 ? "bye" : "pending" }).where(eq(tournamentHeats.id, heat.id));
  }
}

/** Takes an entry out of a running tournament (a bottle ran out). Its decided heats stand; it plays no more. */
export async function withdrawEntry(ownerId: number, tournamentId: number, entryId: number): Promise<Done | Failure> {
  return db.transaction(async (tx) => {
    const t = await lockTournament(tx, ownerId, tournamentId);
    if (!t) return fail(404, GONE);
    if (t.status !== "active") return fail(409, "Only a running tournament has entries to withdraw.");
    const [entry] = await tx
      .select({ id: tournamentEntries.id, status: tournamentEntries.status })
      .from(tournamentEntries)
      .where(and(eq(tournamentEntries.id, entryId), eq(tournamentEntries.tournamentId, t.id)));
    if (!entry) return fail(404, NO_ENTRY);
    if (entry.status === "withdrawn") return fail(409, "That entry is already withdrawn.");

    await tx.update(tournamentEntries).set({ status: "withdrawn" }).where(eq(tournamentEntries.id, entryId));
    await removeFromUndecided(tx, t.id, entryId);
    await settle(tx, ownerId, t);
    return { ok: true as const, view: (await viewOf(tx, ownerId, t.id))! };
  });
}

/** A flight as the pourer sees it: every glass with what is in it. */
export type DrawnHeat = {
  heatId: number;
  round: number;
  slot: number;
  band: string;
  glasses: { glass: string; entry: Pick<ViewHeatEntry, "entryId" | "name" | "proof" | "mashbill" | "ageYears" | "distilleries"> }[];
};

/**
 * Picks a pending flight of the current round at random, labels its glasses at random and keeps the letters, so the
 * pourer knows what is in each glass and the taster sees only letters. Drawing again replaces the letters.
 */
export async function drawHeat(ownerId: number, tournamentId: number): Promise<{ ok: true; heat: DrawnHeat } | Failure> {
  return db.transaction(async (tx) => {
    const t = await lockTournament(tx, ownerId, tournamentId);
    if (!t) return fail(404, GONE);
    if (t.status !== "active") return fail(409, "This tournament is not running.");
    const state = await readState(tx, t.id);
    const round = Math.max(...state.heats.map((h) => h.round));
    const open = state.heats.filter((h) => h.round === round && h.status === "pending");
    if (open.length === 0) return fail(409, "No flight is waiting to be tasted.");

    const heat = open[randomInt(open.length)]!;
    const rows = state.heatEntries.filter((r) => r.heatId === heat.id);
    const letters = LETTERS.slice(0, rows.length);
    for (let i = letters.length - 1; i > 0; i--) {
      const j = randomInt(i + 1);
      [letters[i], letters[j]] = [letters[j]!, letters[i]!];
    }
    await tx.update(tournamentHeatEntries).set({ glass: null }).where(eq(tournamentHeatEntries.heatId, heat.id));
    for (const [i, row] of rows.entries()) {
      await tx
        .update(tournamentHeatEntries)
        .set({ glass: letters[i]! })
        .where(and(eq(tournamentHeatEntries.heatId, heat.id), eq(tournamentHeatEntries.entryId, row.entryId)));
    }

    const entrants = await loadEntrants(tx, ownerId, state.entries.filter((e) => rows.some((r) => r.entryId === e.id)));
    const glasses = rows
      .map((row, i) => {
        const e = entrants.get(row.entryId)!;
        return {
          glass: letters[i]!,
          entry: {
            entryId: row.entryId,
            name: state.entries.find((x) => x.id === row.entryId)!.displayName,
            proof: e.proof,
            mashbill: e.mashbill ? mashbillDisplay(e.mashbill) || null : null,
            ageYears: e.ageYears,
            distilleries: e.distilleries,
          },
        };
      })
      .sort((a, b) => a.glass.localeCompare(b.glass));
    return { ok: true as const, heat: { heatId: heat.id, round: heat.round, slot: heat.slot, band: heatBand([...entrants.values()]), glasses } };
  });
}

/** Sets the glass letters of a pending flight by hand (the solo flow): every entry gets a different letter from A up. */
export async function setGlasses(
  ownerId: number,
  tournamentId: number,
  heatId: number,
  assign: { entryId: number; glass: string }[],
): Promise<Done | Failure> {
  return db.transaction(async (tx) => {
    const t = await lockTournament(tx, ownerId, tournamentId);
    if (!t) return fail(404, GONE);
    if (t.status !== "active") return fail(409, "This tournament is not running.");
    const state = await readState(tx, t.id);
    const heat = state.heats.find((h) => h.id === heatId);
    if (!heat) return fail(404, NO_HEAT);
    if (heat.status !== "pending") return fail(409, "That flight is already decided.");
    const rows = state.heatEntries.filter((r) => r.heatId === heat.id);
    const allowed = new Set(LETTERS.slice(0, rows.length));
    const ok =
      assign.length === rows.length &&
      new Set(assign.map((a) => a.entryId)).size === rows.length &&
      new Set(assign.map((a) => a.glass)).size === rows.length &&
      assign.every((a) => allowed.has(a.glass) && rows.some((r) => r.entryId === a.entryId));
    if (!ok) return fail(422, `Give each bottle in the flight a different letter from ${LETTERS[0]} to ${LETTERS[rows.length - 1]}.`, { assign: "Give each bottle its own letter." });

    await tx.update(tournamentHeatEntries).set({ glass: null }).where(eq(tournamentHeatEntries.heatId, heat.id));
    for (const a of assign) {
      await tx
        .update(tournamentHeatEntries)
        .set({ glass: a.glass })
        .where(and(eq(tournamentHeatEntries.heatId, heat.id), eq(tournamentHeatEntries.entryId, a.entryId)));
    }
    return { ok: true as const, view: (await viewOf(tx, ownerId, t.id))! };
  });
}

/**
 * Moves an entry to another undecided flight of the current round (round 1 in a draft). The flight it joins must have
 * room; one it leaves with a single entry becomes a bye, with none is removed. Refused in a running blind tournament,
 * whose flights are hidden; reset the round instead.
 */
export async function moveEntry(ownerId: number, tournamentId: number, entryId: number, toHeatId: number): Promise<Done | Failure> {
  return db.transaction(async (tx) => {
    const t = await lockTournament(tx, ownerId, tournamentId);
    if (!t) return fail(404, GONE);
    if (t.status === "complete") return fail(409, "This tournament is finished.");
    if (t.status === "active" && t.blind) return fail(409, "The flights of a blind tournament are hidden. Reset the round to regroup it.");
    const state = await readState(tx, t.id);
    if (state.heats.length === 0) return fail(409, "There are no flights yet. Reset the round to make them.");
    const round = Math.max(...state.heats.map((h) => h.round));
    const entry = state.entries.find((e) => e.id === entryId);
    if (!entry) return fail(404, NO_ENTRY);
    if (entry.status !== "active") return fail(409, "A withdrawn entry cannot be moved.");

    const from = state.heatEntries.find((r) => r.entryId === entryId && state.heats.some((h) => h.id === r.heatId && h.round === round));
    const fromHeat = from ? state.heats.find((h) => h.id === from.heatId) : undefined;
    const toHeat = state.heats.find((h) => h.id === toHeatId);
    if (!fromHeat || fromHeat.status === "decided") return fail(409, "That entry is not in an undecided flight of the current round.");
    if (!toHeat || toHeat.round !== round) return fail(404, NO_HEAT);
    if (toHeat.status === "decided") return fail(409, "That flight is already decided.");
    if (toHeat.id === fromHeat.id) return fail(409, "That entry is already in that flight.");
    const toCount = state.heatEntries.filter((r) => r.heatId === toHeat.id).length;
    if (toCount >= t.heatSize) return fail(409, `That flight is full (${t.heatSize} bottles).`);

    await tx.delete(tournamentHeatEntries).where(and(eq(tournamentHeatEntries.heatId, fromHeat.id), eq(tournamentHeatEntries.entryId, entryId)));
    await tx.insert(tournamentHeatEntries).values({ heatId: toHeat.id, entryId, tournamentId: t.id });
    await tx.update(tournamentHeats).set({ status: "pending" }).where(eq(tournamentHeats.id, toHeat.id));
    const left = state.heatEntries.filter((r) => r.heatId === fromHeat.id).length - 1;
    if (left === 0) await tx.delete(tournamentHeats).where(eq(tournamentHeats.id, fromHeat.id));
    else await tx.update(tournamentHeats).set({ status: left === 1 ? "bye" : "pending" }).where(eq(tournamentHeats.id, fromHeat.id));
    if (t.status === "active") await settle(tx, ownerId, t);
    return { ok: true as const, view: (await viewOf(tx, ownerId, t.id))! };
  });
}

/** Matches an outside entry to one of the owner's bottles or labels, so its heats count toward the long-term ranking. */
export async function promoteEntry(
  ownerId: number,
  tournamentId: number,
  entryId: number,
  to: { bottleId: number } | { expressionId: number },
): Promise<Done | Failure> {
  return db.transaction(async (tx) => {
    const t = await lockTournament(tx, ownerId, tournamentId);
    if (!t) return fail(404, GONE);
    const [entry] = await tx
      .select({ id: tournamentEntries.id, bottleId: tournamentEntries.bottleId, expressionId: tournamentEntries.expressionId })
      .from(tournamentEntries)
      .where(and(eq(tournamentEntries.id, entryId), eq(tournamentEntries.tournamentId, t.id)));
    if (!entry) return fail(404, NO_ENTRY);
    if (entry.bottleId !== null || entry.expressionId !== null) return fail(409, "Only an outside entry can be matched.");

    let expressionId: number;
    let bottleId: number | null = null;
    if ("bottleId" in to) {
      const rows = (await tx.execute(sql`SELECT id, expression_id FROM bottles WHERE id = ${to.bottleId} AND owner_id = ${ownerId}`)) as unknown as { id: number; expression_id: number }[];
      if (rows.length === 0) return fail(422, "That bottle is gone.", { bottleId: "That bottle is gone." });
      bottleId = rows[0]!.id;
      expressionId = rows[0]!.expression_id;
    } else {
      const rows = (await tx.execute(sql`SELECT id FROM expressions WHERE id = ${to.expressionId} AND owner_id = ${ownerId}`)) as unknown as { id: number }[];
      if (rows.length === 0) return fail(422, "That label is gone.", { expressionId: "That label is gone." });
      expressionId = rows[0]!.id;
    }
    const taken = await tx
      .select({ id: tournamentEntries.id, bottleId: tournamentEntries.bottleId, expressionId: tournamentEntries.expressionId })
      .from(tournamentEntries)
      .where(and(eq(tournamentEntries.tournamentId, t.id), eq(tournamentEntries.expressionId, expressionId)));
    if (taken.some((e) => (bottleId !== null ? e.bottleId === bottleId : e.bottleId === null))) {
      return fail(409, "That bottle or label is already in this tournament.");
    }
    await tx.update(tournamentEntries).set({ bottleId, expressionId }).where(eq(tournamentEntries.id, entryId));
    return { ok: true as const, view: (await viewOf(tx, ownerId, t.id))! };
  });
}

/** Names a flight, or clears its name with an empty one. */
export async function renameHeat(ownerId: number, tournamentId: number, heatId: number, label: string | null): Promise<Done | Failure> {
  return db.transaction(async (tx) => {
    const t = await lockTournament(tx, ownerId, tournamentId);
    if (!t) return fail(404, GONE);
    const [heat] = await tx
      .select({ id: tournamentHeats.id })
      .from(tournamentHeats)
      .where(and(eq(tournamentHeats.id, heatId), eq(tournamentHeats.tournamentId, t.id)));
    if (!heat) return fail(404, NO_HEAT);
    const clean = label === null ? null : label.trim() === "" ? null : label.trim();
    if (clean !== null && clean.length > 80) return fail(422, "A flight's name can be up to 80 characters.", { label: "Up to 80 characters." });
    await tx.update(tournamentHeats).set({ label: clean }).where(eq(tournamentHeats.id, heat.id));
    return { ok: true as const, view: (await viewOf(tx, ownerId, t.id))! };
  });
}
```

```ts
import { sql, type SQL } from "drizzle-orm";
import { db } from "@/db";
import { competitorId } from "./entrants";
import { audit, rankCompetitors, type AuditRow, type RankedHeat, type Strength } from "./ranking";

const list = (items: (number | string)[]): SQL => sql.join(items.map((i) => sql`${i}`), sql`, `);

export type RankedCompetitor = Strength & {
  name: string;
  /** The bottle or label this competitor is. */
  bottleId: number | null;
  expressionId: number | null;
  /** The average of its 0 to 10 tasting ratings, or null when it has none. */
  rating: number | null;
};

export type RankingResult = {
  competitors: RankedCompetitor[];
  /** Where the ranking and the ratings disagree, biggest gap first. */
  audit: (AuditRow & { name: string })[];
};

type HeatRow = { heat_id: number; place: number; entry_id: number; bottle_id: number | null; expression_id: number | null; display_name: string };

/**
 * The long-term ranking: every decided heat of every one of the owner's tournaments, pooled. Outside (ad hoc) entries
 * are left out of it. With `categoryId`, only competitors whose label is in that category or below it are ranked
 * (a heat's other competitors keep their relative order). Ratings come from the tastings of the same bottle, or, for
 * an entry with no bottle, of the label with no bottle.
 */
export async function rankingFor(ownerId: number, categoryId: number | null): Promise<RankingResult> {
  const run = async <T>(query: SQL): Promise<T[]> => (await db.execute(query)) as unknown as T[];

  const rows = await run<HeatRow>(sql`
    SELECT he.heat_id, he.place, te.id AS entry_id, te.bottle_id, te.expression_id, te.display_name
    FROM tournament_heat_entries he
    JOIN tournament_heats h ON h.id = he.heat_id AND h.status = 'decided'
    JOIN tournaments t ON t.id = h.tournament_id AND t.owner_id = ${ownerId}
    JOIN tournament_entries te ON te.id = he.entry_id
    WHERE he.place IS NOT NULL
    ORDER BY he.heat_id, he.place`);

  type Who = { id: string; bottleId: number | null; expressionId: number | null; name: string; entryId: number };
  const who = new Map<string, Who>();
  const perHeat = new Map<number, string[]>();
  for (const r of rows) {
    const id = competitorId({ bottleId: r.bottle_id, expressionId: r.expression_id });
    if (id === null) continue;
    const seen = who.get(id);
    if (!seen || r.entry_id > seen.entryId) who.set(id, { id, bottleId: r.bottle_id, expressionId: r.expression_id, name: r.display_name, entryId: r.entry_id });
    perHeat.set(r.heat_id, [...(perHeat.get(r.heat_id) ?? []), id]);
  }
  if (who.size === 0) return { competitors: [], audit: [] };

  const bottleIds = [...who.values()].flatMap((w) => (w.bottleId !== null ? [w.bottleId] : []));
  const labelIds = [...who.values()].flatMap((w) => (w.bottleId === null && w.expressionId !== null ? [w.expressionId] : []));
  const expressionIds = [...new Set([...who.values()].flatMap((w) => (w.expressionId !== null ? [w.expressionId] : [])))];

  const proofOfBottle = new Map(
    (bottleIds.length ? await run<{ id: number; proof: string | null }>(sql`SELECT id, proof FROM bottle_list WHERE owner_id = ${ownerId} AND id IN (${list(bottleIds)})`) : []).map((r) => [r.id, r.proof]),
  );
  const expressionRows = expressionIds.length
    ? await run<{ id: number; proof: string | null; category_id: number }>(sql`SELECT id, proof, category_id FROM expressions WHERE owner_id = ${ownerId} AND id IN (${list(expressionIds)})`)
    : [];
  const expressionById = new Map(expressionRows.map((r) => [r.id, r]));

  let allowedCategories: Set<number> | null = null;
  if (categoryId !== null) {
    const tree = await run<{ id: number }>(sql`WITH RECURSIVE tree AS (
      SELECT id FROM categories WHERE id = ${categoryId}
      UNION ALL SELECT c.id FROM categories c JOIN tree ON c.parent_id = tree.id) SELECT id FROM tree`);
    allowedCategories = new Set(tree.map((r) => r.id));
  }
  const inScope = (w: Who) => allowedCategories === null || (w.expressionId !== null && allowedCategories.has(expressionById.get(w.expressionId)?.category_id ?? -1));
  const proofOf = (w: Who): number | null => {
    const raw = w.bottleId !== null ? proofOfBottle.get(w.bottleId) : w.expressionId !== null ? expressionById.get(w.expressionId)?.proof : null;
    const n = raw === null || raw === undefined ? NaN : Number(raw);
    return Number.isFinite(n) ? n : null;
  };

  const heats: RankedHeat[] = [...perHeat.values()].map((ids) => ({
    ranking: ids.filter((id) => inScope(who.get(id)!)).map((id) => ({ id, proof: proofOf(who.get(id)!) })),
  }));
  const strengths = rankCompetitors(heats);

  const ratingRows = [
    ...(bottleIds.length
      ? await run<{ bottle_id: number; avg: string }>(sql`SELECT bottle_id, avg(rating) AS avg FROM tasting_notes WHERE owner_id = ${ownerId} AND rating IS NOT NULL AND bottle_id IN (${list(bottleIds)}) GROUP BY bottle_id`)
      : []
    ).map((r) => ["b:" + r.bottle_id, Number(r.avg)] as const),
    ...(labelIds.length
      ? await run<{ expression_id: number; avg: string }>(sql`SELECT expression_id, avg(rating) AS avg FROM tasting_notes WHERE owner_id = ${ownerId} AND rating IS NOT NULL AND bottle_id IS NULL AND expression_id IN (${list(labelIds)}) GROUP BY expression_id`)
      : []
    ).map((r) => ["e:" + r.expression_id, Number(r.avg)] as const),
  ];
  const ratings = new Map<string, number | null>(ratingRows.map(([id, avg]) => [id, Math.round(avg * 10) / 10]));

  return {
    competitors: strengths.map((s) => {
      const w = who.get(s.id)!;
      return { ...s, name: w.name, bottleId: w.bottleId, expressionId: w.expressionId, rating: ratings.get(s.id) ?? null };
    }),
    audit: audit(strengths, ratings).map((row) => ({ ...row, name: who.get(row.id)!.name })),
  };
}
```

```ts
import { NextResponse, type NextRequest } from "next/server";
import type { z } from "zod";
import { getCurrentUser } from "@/lib/auth";
import { apiError, issueFields, parseId, readJsonObject, type ApiErrorBody } from "@/lib/api/v1";
import type { Failure } from "./state";

type Halt = { response: NextResponse<ApiErrorBody> };

/** The signed-in user, or the 401 to answer with. */
export async function authed(): Promise<{ userId: number } | Halt> {
  const user = await getCurrentUser();
  return user ? { userId: user.id } : { response: apiError(401, "unauthorized", "Sign in first.") };
}

/** A request's JSON body checked against `schema`, or the 415, 400 or 422 to answer with. */
export async function parsed<T extends z.ZodType>(request: NextRequest, schema: T): Promise<{ data: z.infer<T> } | Halt> {
  const read = await readJsonObject(request);
  if ("error" in read) return { response: read.error };
  const result = schema.safeParse(read.body);
  if (!result.success) {
    return { response: apiError(422, "invalid", result.error.issues[0]?.message ?? "Check the fields.", issueFields(result.error.issues)) };
  }
  return { data: result.data };
}

/** Path ids as numbers, or the 404 to answer with. */
export function ids<K extends string>(params: Record<K, string>, gone: string): Record<K, number> | Halt {
  const out = {} as Record<K, number>;
  for (const key of Object.keys(params) as K[]) {
    const n = parseId(params[key]);
    if (n === null) return { response: apiError(404, "not_found", gone) };
    out[key] = n;
  }
  return out;
}

/** A command that could not be done, as the API's error body. */
export function failed(f: Failure): NextResponse<ApiErrorBody> {
  return apiError(f.status, f.status === 404 ? "not_found" : f.status === 409 ? "conflict" : "invalid", f.message, f.fields);
}

export const isHalt = (value: object): value is Halt => "response" in value;

export const json = (body: unknown, status = 200): NextResponse => NextResponse.json(body, { status });
```

```ts
import { apiError, parseId } from "@/lib/api/v1";
import { authed, isHalt, json } from "@/lib/tournaments/http";
import { rankingFor } from "@/lib/tournaments/ranking-query";

export const dynamic = "force-dynamic";

/**
 * The long-term ranking across all your tournaments, and where it disagrees with your 0 to 10 ratings (`audit`).
 * `?categoryId=` ranks only bottles whose label is in that category or below it. Outside entries are never ranked.
 * Each competitor has a `group`: only competitors in the same group can be compared.
 */
export async function GET(request: NextRequest): Promise<NextResponse> {
  const auth = await authed();
  if (isHalt(auth)) return auth.response;
  const raw = request.nextUrl.searchParams.get("categoryId");
  const categoryId = raw === null ? null : parseId(raw);
  if (raw !== null && categoryId === null) return apiError(422, "invalid", "categoryId must be a category id.", { categoryId: "Not a category id." });
  return json(await rankingFor(auth.userId, categoryId));
}
```
