# Fill Dial Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the fuel-dial fill gauge on web and iOS: fine 5% ticks, a sealed state, and a dial-only nudge after a new tasting from an owned bottle.

**Architecture:** The stored value stays an integer percent. Dial maths and the sealed rule live in small pure functions that both platforms mirror and unit-test; the components only draw and forward input. The nudge reuses the existing fill control on each platform instead of adding a second way to set the level.

**Tech Stack:** Next.js / React / TypeScript / Vitest / Playwright (web); SwiftUI / XCTest, built and tested on the iMac with `mac-build` (iOS).

**Spec:** `docs/superpowers/specs/2026-10-27-fill-dial-design.md`

## Global Constraints

- Stored value: integer percent 0 to 100 in `fill_pct`; nothing on screen shows a percentage as the headline.
- Ticks every 5%; major (longer) ticks at 0, 25, 50, 75, 100; labels `E`, `¼`, `½`, `¾`, `F`.
- Pointer or touch detents to the nearest 5%; below 3% from the left end reads as 0.
- Readout words stay on the existing six states (`Full`, `¾ full`, `½ full`, `¼ full`, `Almost gone`, `Empty`); a sealed bottle reads `Sealed`.
- Low-fuel red below 18%, the same line the quick states use between Almost gone and ¼.
- Sealed = `effectiveBottleStatus(b) === "owned"` (status `owned`, not open, fill 100). Sealed dial: hatched track, wax seal, no needle. Below 64px high (web) or in thin lists: hatched track only, no seal icon.
- No "Open" chip and no "open since" date on the dial.
- Keyboard (web): arrow keys move one tick (5%), Shift moves a quarter (25%), Home = Empty, End = Full. iOS VoiceOver adjustable action moves one tick.
- Nudge only for a **new** tasting from the owner's **own, non-killed** bottle; never for edits, bar, sample, bottle share, store pour or "not from my collection". It shows the dial at the current level and suggests nothing; skipping changes nothing.
- Spring needle and haptic ticks are off under reduced motion.
- Out of scope: pour counts, bottle-size scaling, the `pours` table, automatic decrement, the iOS thin capsule gauges (`CollectionView`, `TonightResult`, `LogTastingFlow`, `BottleCard`).

## Review Focus

1. **Stored value not on a tick** (an imported 63%, a stray 1%): needle at its exact place, readout by the existing band, first nudge or key press moves to the next tick in that direction. Pinned in Task 1.
2. **A bottle that looks sealed but isn't** (`owned`, not flagged open, fill under 100): treated as open, never hatched. Pinned in Task 1.
3. **Killed and wishlist bottles:** never sealed, never nudged. Pinned in Tasks 1, 4 and 6.
4. **Edits and non-owned tastings:** no nudge. Pinned in Tasks 4 and 6.
5. **Pointer edge cases:** a touch level with the hub, below it, or outside the dial reads as the nearer peg; 1–2% is Empty, never a stray 0 → 5 jump. Pinned in Tasks 1 and 5.
