Type a name in the Distilled by row. Pick an existing distillery, or choose “Add details…” to open the popup. “or not disclosed” opens a small place popup. The demo bar changes which kind of spirit is being added, which changes the country, the offered list and the identifier fields.

What changed, and what stayed
  • Kept: Name (required), Company, City, State, Country (required, set from the label's category when it has a rule), Founded, Defunct, Scotch Region, DSP number, NOM, Other / Old Names, and Notes. A US state typed as “KY” is tidied to “Kentucky”, as today. A distillery's company is pre-filled when the name you typed matches the label's brand.
  • “How Known” is gone, since “not disclosed” has its own path (below).
  • “Or not disclosed (pick the place)” opens a small popup for a place only. It keeps one “Undisclosed (place)” entry per place and reuses it when it exists.
  • Place is one line: City, State, Country, and then only the identifier that applies, next to Country: DSP for the USA, NOM for any agave label (tequila or mezcal) or a Mexican distillery, Region for a Scotch label or a Scottish distillery. Today all three always show. Founded, Defunct, old names and notes sit under More.
  • Warnings are in the footer, left of Cancel, in the same amber style as the mashbill popup. A name that already exists blocks Save and offers “Use it”, because names must be unique.
  • “Create …” (name only) stays for every spirit, and fills in the country from the label's category: Mexico for agave, France for the French brandies, Canada, Ireland and so on (Scotland for Scotch is my addition). The rest can be added later.
  • My proposal: when the country doesn't fit the spirit (a tequila distillery outside Mexico), an amber warning says it won't be offered for this label. It doesn't block.
